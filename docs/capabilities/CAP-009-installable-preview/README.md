# Installable preview and existing-robot setup

People with existing Classic Java robot jars can unpack the bridge, find their collection, and create a Tank Royale bot root without development tools or a Classic runtime. The archive carries its libraries, notices, source revision and checksums. The packaged Java command discovers conventional Classic installations, reads rumble repository settings and asks when a source cannot be selected unambiguously.

Source collections stay unchanged. Generated bots and their learned data live in a separate output root. Repeated imports preserve learned data, identify duplicate inputs by content and refuse conflicting generated identities or incomplete teams. [The user guide](../../../guide/README.md) explains installation, first battles and recovery.

This capability proves package assembly and setup. A completed battle is not proof of Classic behavioral parity; the compatibility campaign owns that evidence. The separate preview-readiness milestone owns the clean-environment maintainer walkthrough and platform publication decision.

## Corpus activation

The implemented package criteria have executable evidence. Capability activation remains pending human verification of the inherited high-cost source-collection constraint (C-007); this does not replace the separate preview-readiness walkthrough.
